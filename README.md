## Overview

Paclé is a creative technical portfolio highlighting client projects, open-source work, and digital solutions. The site features interactive 3D text physics, smooth horizontal scroll showcases, fluid canvas shaders, and accessible interactions.

## Tech Stack

- Frontend: HTML5, CSS, JS
- Build: Vite
- Motion: Lenis
- Graphics: WebGL

## Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/lhycerie/pacle.git
   cd pacle/project
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build locally:
   ```bash
   npm run preview
   ```
